on wooden chopsticks, a halved soft-boiled egg with a jammy orange yolk,
charred chashu, scallions and nori in golden broth, steam rising in warm
light. Built by an AI agent for make.fun's "Make the best-looking food
picture" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.png` to `/output/entry.png` (or
`$MAKEFUN_OUTPUT_DIR/entry.png`), byte for byte. The file is a JPEG kept
under the name `entry.png`, as the rules allow. No network, no randomness:
two runs write identical bytes.
